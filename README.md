💻 Diseño de Hardware – Rubio Logistics S.L.
📘 Resumen
Este documento describe el hardware necesario para una pequeña empresa de logística. El objetivo es ofrecer equipos adecuados para cada puesto, con buen rendimiento, bajo coste y fácil mantenimiento.

👨‍💼 Administrador
Equipo:

Portátil HP (Intel Core i7 vPro)

Monitor 24"

Motivo:  
Necesita movilidad y potencia para supervisar la empresa y trabajar desde distintos lugares.

👩‍💻 Recepción
Equipo:

Mini PC tipo NUC

Monitor 24"

Impresora térmica

Motivo:  
Puesto compacto para tareas de atención al cliente, registro de paquetes e impresión de etiquetas.

👩‍💼 Administración
Equipo:

PC sobremesa (Intel Core i5, 16 GB RAM, SSD)

Monitor 24"

Acceso a impresora láser

Motivo:  
Equipo estable y rápido para contabilidad, facturación y gestión documental.

🖨️ Sistema de impresión
Impresora láser compartida: documentos administrativos.

Impresora térmica: etiquetas de envío.

🌐 Red
Router para conexión a internet.
Router → Switch → Puestos (Administrador, Recepción, Administración)
                     ↓
               Impresora térmica

Conclusión:  
El diseño de hardware propuesto cubre las necesidades reales de la empresa, optimiza costes y garantiza un funcionamiento estable en cada puesto.
